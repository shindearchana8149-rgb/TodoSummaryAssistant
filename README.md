# Todo Summary Assistant

A full-stack Todo application with AI-powered summary generation.

## Features
- Add, Edit, Delete Todos
- Mark as complete
- AI Summary of pending todos using OpenAI/Cohere
- Send summary to Slack

## Tech Stack
- **Backend:** Spring Boot, Java 17, Maven, MySQL
- **Frontend:** React.js
- **AI:** OpenAI / Cohere API
- **DevOps:** Docker, Docker Compose, GitHub Actions CI/CD

## How to Run Locally

### Using Docker (Recommended)
```bash
docker-compose up --build
